# Security Policy

## Supported Versions

The following projects and versions receive active security updates:

| Project | Supported |
|---------|-----------|
| Life OS v2 (dev/ins1ght/products/life-os-v2/) | Latest release |
| Odysseus (odysseus/) | Latest release |
| insightful-hub (dev/insightful-hub/) | Latest release |
| codeSpace (@insightful/codeSpace) | Latest release |

Unsupported versions should upgrade to the latest release to receive fixes.

## Reporting a Vulnerability

Report security vulnerabilities to **kyler@insightful-projects.com**.

### What to Expect

- **Acknowledgment**: Within 72 hours of submission
- **Assessment**: A preliminary assessment within 5 business days
- **Fix timeline**: Critical/high severity issues are prioritized within 14 days
- **Disclosure**: Once a fix is released, we coordinate public disclosure

Please include:
- Project name and version
- Description of the vulnerability and impact
- Steps to reproduce (PoC preferred)
- Any suggested mitigation

We follow coordinated disclosure and request that vulnerabilities are not
published until a fix has been released.

## Scope

This policy applies to all repositories under the Insightful Projects
organization, including:
- Life OS v2 (Vue 3 + NestJS stack)
- Odysseus (AI workspace & LLM proxy)
- insightful-hub (backend hub & shared packages)
- @insightful/codeSpace (shared types & domain objects)
